phlegm runs language models on the NPU of AMD Ryzen AI processors with kernels written in the open, from the
IRON / mlir-aie toolchain. No closed NPU binaries are involved.

It is early. The kernels already run whole models, through the openflowlm-next engine. The phlegm engine, its
command line and the Windows tray app are being rebuilt in this repository.
