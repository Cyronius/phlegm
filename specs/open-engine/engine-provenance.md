# C++ engine provenance and intake

Every engine change records its origin, author, date, licence and upstream status when it lands. FLM-derived source retains FLM's copyright and MIT permission notice. ArtLite supplies ideas only: no ArtLite code enters the MIT engine or an OFLM contribution without explicit relicensing by the relevant copyright holder.

Audit date: **2026-11-10**, item **P1 S3b intake**. This is a survey and proposed intake, not an engine merge. The companion [JSON ledger](engine-provenance.json) is the exhaustive inventory of commits, patches, affected files, authors, hashes, evidence and decisions. New patches land separately after S3, with the gates below. The S3 import and its integration changes are owned by another worker.

Evidence notation throughout: **[m]** checked locally in this intake (application/compilation/counts, never a speed claim); **[d]** documented by the cited source, git record, API response or plan; **[i]** inference or proposed benefit; **[h]** hearsay. No hearsay is used to accept an intake candidate. A previous plan's hardware result remains [d] here, not a new measurement.

## FLM relationship and licence boundary

[d] OFLM calls itself a community fork of FastFlowLM in its README. Its first git commit, `03951d97`, is an import with no FLM parent history. Comparing its tree with historical FLM candidates on 2026-09-01/02 found **873 byte-identical shared paths out of 874** at FLM **`6002e0f3`**; the only different shared path is `.gitmodules`. All shared source files match. Later `66999399` / `d5b598c6` match only 829 shared paths, and earlier `8a38c7b7` matches 869. The JSON preserves the selected source pin and the raw historical tree hashes.

[i] FLM `6002e0f3` is therefore the strongly supported source snapshot behind OFLM's import. This is **content ancestry**, not a git merge-base or an explicit upstream fork-revision declaration. It cannot prove how the files were transferred or exclude an unrecorded equivalent snapshot.

[d] `src/open_qwen36/` is absent from both that historical FLM tree and OFLM's initial import. OFLM [PR6](https://github.com/Atomic-Germ/openflowlm-next/pull/6), merged as `8ddb25070482c6067528e1b4378e2d199575be3a`, introduces the open engine, authored by **Cyronius/Cyrus Attoun**. Its commit message describes the new resident interpreter, standalone reader and manifest packer; `engine.hpp` and the README describe it as the open replacement behind the existing `causal_lm` seam. This is evidence for a new open implementation, not source descent from FLM's closed inference DLL.

[d] The inherited FLM host seam includes `src/include/{causal_lm,buffer,lm_config,device_runtime}.hpp` and utility headers. `engine.cpp/.hpp` adapt to it; they are new OFLM files with inherited API dependencies, not renamed FLM engine source files. These general headers are **not** in S3's `src/include/nlohmann` subset and are **not** required by the standalone bridge's six engine translation units. The JSON lists the support-header content comparisons individually. Nlohmann headers are third-party MIT source carried by both trees, retaining **Niels Lohmann** and, for Hedley, **Evan Nemerson** notices; do not attribute them to AMD merely because FLM shipped them.

[d] Independently inspected at the FLM pin: [`LICENSE_RUNTIME.txt`](https://github.com/FastFlowLM/FastFlowLM/blob/74990da2dd7c834eb8a38173ed93d61944d7ee3f/LICENSE_RUNTIME.txt) starts:

> MIT License
>
> Copyright (c) 2026 Advanced Micro Devices, Inc.

[d] It contains the standard MIT grant, notice-retention condition and warranty disclaimer. `THIRD_PARTY_NOTICES.txt` explicitly assigns source to that licence, while [`LICENSE_BINARY.txt`](https://github.com/FastFlowLM/FastFlowLM/blob/74990da2dd7c834eb8a38173ed93d61944d7ee3f/LICENSE_BINARY.txt) covers `.xclbin` and prebuilt NPU engine libraries as **not open source**. Host source may be ported with its notice; no proprietary kernels, corelib/engine libraries, or code inferred from those binaries is part of this intake. No new FLM code has been copied into Phlegm by this survey.
